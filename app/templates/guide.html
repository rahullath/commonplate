commonplate is direct ordering for small kitchens: menu, cart, UPI or cash checkout, a kitchen screen, tracking and WhatsApp updates. No commission, no middleman, open source.

See a live kitchen: {{ demo_url.split('//')[1] }} Try the sample menu here

1. See it working

The live demo at {{ demo_url.split('//')[1] }} is a real kitchen running this code. Place a test order there, then open its kitchen screen to see the other side. On this deployment, /menu shows the sample kitchen and /kitchen is the kitchen screen (it asks for your ADMIN_TOKEN).

2. Host it where the data survives

The app is one process with a SQLite file, so it needs a disk that persists. Use the included Dockerfile on Railway, Fly.io, Render or any small server, and mount a volume at /data.

git clone {{ repo }}
cd commonplate
docker build -t commonplate .
docker run -p 8000:8000 -v commonplate-data:/data \
  -e ADMIN_TOKEN=pick-a-long-secret \
  -e BIZ_SITE_URL=https://your-domain.com \
  -e BIZ_NAME="Your Kitchen" commonplate

Vercel works for previews of the look and feel, not for taking orders.

3. Make it yours

ADMIN_TOKENPassword for the kitchen screen and admin. Set a long random value.
BIZ_SITE_URLYour real https address. Drives links, the sitemap and search listings.
BIZ_NAME, BIZ_PHONE, BIZ_CITY…Name, phone, address and opening hours. Full list in .env.example.
data/menu.jsonYour menu. A sample is included; replace it.
OptionalWhatsApp, Petpooja, couriers, Twilio and Telegram stay off until you add their keys.

4. Go live

Open the kitchen screen on the counter device, place a test order, and check the WhatsApp message arrives. Then submit /sitemap.xml in Google Search Console so customers can find you.
