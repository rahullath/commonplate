# Design source

`commonplate.dc.html` is the original design for the `/commonplate` page, kept for reference.
It runs on the design tool's `support.js` runtime (this folder), which pulls React and Babel from
unpkg. To view it, serve this folder and open the file:

    python3 -m http.server 8770 --directory docs/source
    # then open http://localhost:8770/commonplate.dc.html

(`support.js` is generated by the design tool; do not edit it.)

The live page is `app/templates/commonplate.html` (content in `app/marketing.py`). It is a port of
this design with no runtime, so it is crawlable and fast. If you change the design, port the change
there; nothing serves these files.
